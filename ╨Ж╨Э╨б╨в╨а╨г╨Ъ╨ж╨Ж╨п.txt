1. У GitHub відкрийте theme.js і замініть його вміст вмістом нового theme.js. Натисніть Commit changes.
2. У index.html внизу змініть <script src="./theme.js?v=1"></script> на <script src="./theme.js?v=2"></script> і збережіть.
3. Закрийте застосунок на телефоні й відкрийте повторно. За потреби почекайте оновлення GitHub Pages.
4. Перевірте Календар, Зараз, Архів та Усі.
Примітка: Push-сповіщення не підключаються. Існуючі записи, пошук та оновлення даних залишаються.
