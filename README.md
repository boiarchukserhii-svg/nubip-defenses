# Календар захистів дисертацій НУБіП України

**Публічний вебзастосунок без встановлення Python на комп'ютері користувача.** Інтерфейс розміщується на GitHub Pages, а GitHub Actions раз на три години збирає дані з `https://nubip.edu.ua/defend` у `data.json`.

## Одноразове розгортання (потрібен обліковий запис GitHub)

1. Створіть **публічний** репозиторій GitHub, наприклад `nubip-defenses`. Завантажте **всі файли та приховану папку `.github`** з цього архіву в корінь репозиторію. Зручно завантажити через GitHub Desktop або Git.
2. У **Settings → Actions → General → Workflow permissions** встановіть **Read and write permissions** (для запису `data.json`).
3. У **Actions → Оновлення захистів → Run workflow** запустіть перше наповнення. Переконайтеся, що виконання зелене і файл `data.json` містить записи.
4. У **Settings → Pages → Build and deployment** оберіть **Deploy from a branch**, `main`, `/ (root)` і збережіть.
5. Після публікації сайт відкриватиметься за адресою `https://ВАШ_ЛОГІН.github.io/nubip-defenses/` (фактична адреса залежить від назви репозиторію).

**Поточний `data.json` порожній навмисно:** не підставляємо вигадані дані. Після успішного запуску workflow він заповниться реальними записами. Сайт має відкриватися навіть до першої синхронізації.

## Особливості й обмеження

- Збираються всі записи з датою **від 1 січня 2026 року**, включно з майбутніми захистами. Записи зберігаються при наступних синхронізаціях.
- Перевірка виконується приблизно раз на три години; GitHub Actions може запускати заплановані завдання із затримкою або призупиняти їх для неактивних репозиторіїв.
- Якщо офіційний сайт змінить структуру або заблокує автоматичні запити, workflow завершиться помилкою, а попередній `data.json` залишиться доступним. Потрібно буде виправити парсер.
- Якщо сайт НУБіП показує суперечливі дати на сторінці списку та в детальній картці, автоматичний збір використовує дату зі списку. Для юридично значущої інформації перевіряйте офіційну сторінку захисту.
- Це незалежний інформаційний застосунок, а не офіційний сервіс університету.

## Локальна перевірка розробником

```bash
pip install -r requirements.txt
python scraper.py
python -m http.server 8000
```

Потім відкрити `http://localhost:8000`.
