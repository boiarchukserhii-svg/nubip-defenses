Захисти дисертацій НУБіП — версія 5.0 (синьо-біла PWA)

1. На GitHub у корінь репозиторію завантажте index.html, manifest.webmanifest, service-worker.js, а також папку icons з двома PNG.
2. НЕ видаляйте data.json, scraper.py, names.py, requirements.txt і .github.
3. GitHub Pages оновить сайт після Commit changes.
4. Відкрийте https://boiarchukserhii-svg.github.io/nubip-defenses/ у Chrome на Android або Chrome/Edge на Windows.
5. У меню браузера виберіть Встановити застосунок.

Примітка: для встановлення потрібен HTTPS. Оновлення бази відбувається на GitHub кожні 3 години, а застосунок отримує свіжі дані при відкритті/оновленні за наявності інтернету.
