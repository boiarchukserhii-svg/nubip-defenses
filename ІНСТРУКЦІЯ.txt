ОНОВЛЕННЯ ЗАСТОСУНКУ «ЗАХИСТИ»

1. Розпакуйте архів. У корінь boiarchukserhii-svg/nubip-defenses завантажте із заміною: index.html, theme.js, cleanup.css, service-worker.js, manifest.webmanifest. Інші файли можна залишити на місці: усі 147 записів у data.json збережені без змін.
2. Щоб старий розклад не перезаписав дані, у GitHub відкрийте Actions → «Оновлення захистів» → меню ⋯ → Disable workflow. Або замініть наявний .github/workflows/update-defenses.yml файлом із такої ж папки архіву: нова версія лише перевіряє JSON за ручним запуском, нічого не завантажує з НУБіП.
3. Збережіть зміни (Commit changes) і дочекайтеся публікації GitHub Pages. Закрийте й відкрийте застосунок двічі, щоб встановлений застосунок отримав новий інтерфейс.

НАДАЛІ
Нові захисти додаємо до власного data.json. updated_at — дата фактичного оновлення змісту у форматі ISO з часовим поясом. Заміна оформлення не змінює цю дату. Застосунок читає лише власний data.json; після першого відкриття з інтернетом зберігає дані для роботи офлайн. Зовнішні посилання та Google Календар потребують інтернету.
