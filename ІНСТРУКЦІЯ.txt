Оновлення логотипу НУБіП, версія 6

1. Розпакуйте архів.
2. У корені репозиторію GitHub завантажте ЧОТИРИ файли (без папки icons):
   icon-192.png, icon-512.png, nubip-logo-blue.png, brand.js
   Для перших двох підтвердіть заміну старих файлів.
3. Відкрийте index.html → Edit (олівець).
   Перед </body> вставте окремий рядок:
   <script src="./brand.js?v=6"></script>
   Збережіть Commit changes.
4. Після оновлення GitHub Pages відкрийте сайт і натисніть Ctrl+F5.
5. Якщо застосунок уже встановлено, перезапустіть його або перевстановіть, щоб оновилася іконка.

Символіка: синьо-білий варіант з офіційного брендбуку НУБіП, версія 2.1, стор. 5.
Увага: цей комплект змінює лише оформлення, не чіпає scraper.py, data.json і логіку календаря.
